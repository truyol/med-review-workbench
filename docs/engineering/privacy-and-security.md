# 隐私与安全基线

## 数据

- 只使用公开、去标识化或物理模体数据，记录来源、许可、获取日期和使用范围。
- 不提交完整大型数据集；提供获取说明、哈希和最小样例范围。
- 原始素材只读保存，派生预览与原文件分离。

## DICOM

- 只展示明确 allowlist 中的元数据。
- 不展示或记录 PatientName、PatientID、PatientBirthDate、InstitutionName 等敏感字段。
- “未发现已知字段”不等于证明已经完全去标识化；界面必须保留来源/去标识化状态。

## 文件

- UUID 作为存储名和日志标识；原文件名只在受控元数据中保存。
- 验证扩展名、内容特征、大小和路径，防止路径穿越与伪造格式。
- 压缩包支持如进入后续范围，必须限制解压大小、文件数和路径。

## 日志与错误

- 记录 request ID、路由、状态码、耗时、素材 UUID 和稳定错误码。
- 不记录请求正文、原文件名、原始 DICOM 标签集合或堆栈到客户端。
- 审计日志与运行日志分离。

本项目仅展示隐私设计与工程实践，不宣称获得医疗器械、HIPAA 或其他法规认证。
