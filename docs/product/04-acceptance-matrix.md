## 验收原则

- 必须有明确输入、预期结果和证据位置。
- “页面看起来完成”不视为通过。
- 必须 需求优先形成一条完整闭环；应该 需求不阻塞主流程交付。
- 涉及 DICOM、日志和文件名的验收必须包含隐私检查。

## P8 自动化追溯结果（2026-09-21 最新复验）

详细环境、测试数量、覆盖率和风险见 `docs/product/12-p8-test-report.md`。P8 对现有能力的自动化门禁已通过，但对原始需求不虚报完整满足：

- FR-001 至 FR-011 的当前实现路径均有 API、组件或真实后端 E2E 证据，但 FR-002/004 的逐素材来源/脱敏状态和 FR-007 的必填文本仍只部分满足。完整人工演示列为 P10 待确认项；测试数量以最新完整门禁输出和 P8 报告为准。
- FR-004/008 的素材标签/备注与类型/状态/标签筛选已补齐；FR-009 双图并排比较已补齐。
- FR-006 的结构标记持久化由 API 和真实后端 E2E 覆盖；旋转/缩放/平移的手势精度仍需人工演示确认，不能宣称像素级自动验证。
- NFR-002 的 SQLite 路径已验证；PostgreSQL 只说明切换方式和限制，不声称完成生产验证。
